# Detailed session notes (optional, one file per person)

`PROGRESS.md` §9 holds the short, **append-only** session log: one line per session, under your own name.

If you want more detail, such as verification output, commands you ran or problems you hit, add it to `docs/progress/<your-first-name>.md`:
- **append only**, newest entry at the bottom;
- each entry starts with `## YYYY-MM-DD · <task ids> · <branch>`;
- edit only your own file, so it can never conflict with anyone else's.
